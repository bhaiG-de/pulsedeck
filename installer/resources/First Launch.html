● pulsedeck / macOS installation

Your first launch, step by step.

In the PulseDeck disk image, double-click Install PulseDeck.app to open the custom installer.

Seeing “Install PulseDeck.app Not Opened”?

This release has not been notarized by Apple, so macOS may block its first launch. If you trust your download from the official PulseDeck release, you can approve this app in macOS.

  1. Try opening Install PulseDeck.app once. Dismiss the warning with Done.
  2. Open System Settings → Privacy & Security. Scroll down to Security and find the message naming Install PulseDeck.app.
  3. Click Open Anyway, authenticate if asked, and confirm Open. The custom installer can now launch.
Open Privacy & Security ↗

You can also double-click “Open Privacy & Security.inetloc” in the disk image. The shortcut opens settings; you choose whether to approve the app.

Finish in the custom installer

Choose DJ skills for Codex, Claude Code, or both. Click Install PulseDeck or drag its icon to the Applications target, then choose Open PulseDeck.

If macOS also blocks PulseDeck.app, repeat the approval steps for that app. Restart Codex or Claude Code after installing their skills.

On macOS 12, use System Preferences → Security & Privacy → General. If the shortcut does not open the right page, navigate there manually. If Open Anyway is missing, try opening the installer again; a managed Mac may require your administrator’s approval.
